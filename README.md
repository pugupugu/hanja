# 한문 첫걸음

중학생을 위한 초급 한문 학습 웹 프로그램입니다. 서버 없이 동작하는 정적 웹(HTML·CSS·JavaScript)입니다.

## 기능
- **배우기**: 기초 한자 123자, 10개 단원 플래시카드 (훈·음, 예시 한자어, 팁)
- **퀴즈**: 한자→훈음, 훈음→한자, 한자어 읽기, 사자성어 빈칸, 섞어서
- **사자성어**: 28개, 글자 풀이·뜻·예문
- **쓰기 연습**: 본보기 글자를 따라 쓰는 캔버스
- **오답노트**: 틀린 문제 자동 저장, 오답만 다시 풀기

학습 기록은 브라우저(localStorage)에 저장됩니다.

## 실행
`index.html`을 브라우저로 열면 됩니다.

## GitHub Pages 배포
1. 이 파일들을 저장소 최상위에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 지정합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

## 파일 구성
```
index.html      시작 화면
css/style.css   디자인
js/data.js      한자·사자성어 데이터 (여기서 추가/수정)
js/app.js       기능
```
